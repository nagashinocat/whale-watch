# クジラの見える海 Web試作品 設計書

- 作成日: 2026-11-05
- 対象: ステップ1(Web試作品)。スマホアプリ化(ステップ2)と公開(ステップ3)は別の設計書で扱う。

## 1. 目的と使われ方

### 目的
定点カメラで海を眺めているような画面と波の音を、流しっぱなしで楽しめるアプリ。
主な役割は「癒やしの環境音」で、そこにホエールウォッチングの要素(ときどきクジラが現れる)を少しだけ混ぜる。

### 想定する使われ方
- 赤ちゃんのいる家庭で、寝かしつけ用のホワイトノイズとして流す
- 作業中などに、何か音を流しておきたいときのBGMとして使う
- 画面は見ても見なくてもよい。たまたま見ていた人がクジラに会えると嬉しい
- クジラをすぐ見たい人は「呼ぶ」ボタンで呼べる

### 想定する機器
- 主にスマホ・タブレット(最終的にはどの機器でも使えるのが理想)
- 試作品はブラウザで動かす。画面オフでの音の継続はステップ2(アプリ化)で対応する

### 成功の条件
- 一晩流しても、突然大きな音が鳴らない
- 長時間流しっぱなしでも快適に動く
- 流していると、ときどきクジラの気配を感じられ、たまに大当たり(大ジャンプ)に出会える

## 2. 画面と操作

### 起動
- 海の画面に「タップしてはじめる」とだけ表示する
- タップすると波の音がフェードインで始まる(ブラウザは操作なしに音を流せないため)

### ふだんの画面
- 画面いっぱいに海。カメラは三脚で固定したように動かない
- ボタン類は一切表示しない

### メニュー
- 画面をタップすると下にメニューが出る。数秒操作しなければ自動で消える
- 項目:
  1. おやすみ / ふつう の切り替え
  2. クジラを呼ぶボタン
  3. 音量スライダー
  4. カメラ位置の選択(崖の上 / 船の上 / 浜辺 / 水面すれすれ)
  5. 全画面表示
- メニューの片すみに音源などのクレジットを小さく表示する
- 音量・モード・カメラ位置は保存し、次に開いたときも同じ設定で始める

### カメラ位置(メニューから選択。選んだらそのまま固定)
| 位置 | 特徴 |
|---|---|
| 崖の上 | 高い位置から広い海を見渡す。クジラを見つけやすい |
| 船の上 | 甲板からの視点。わずかに揺れる |
| 浜辺 | 波打ち際の景色。一番リラックス向き |
| 水面すれすれ | 海面ぎりぎりの目線。クジラ出現時の迫力が一番 |

## 3. 全体の構成(部品)

部品ごとに役割を分け、ステップ2のアプリ化でも持っていきやすくする。

| 部品 | 役割 |
|---|---|
| 海と空 | 波・空・時刻による変化・カメラ位置を描く |
| クジラの出番係 | 次にいつ、どの出方でクジラを出すかを決める。描画や音には直接触らない |
| クジラの演出 | 出番係から指示された出方を、3Dモデルとエフェクトで見せる |
| 音 | 波の音・クジラの声・しぶき音をモードと音量に合わせて鳴らす |
| メニュー | 操作を受け付け、設定を保存する |

出番係は「出方の種類」と「開始時刻」を通知するだけにし、演出と音はその通知を受けてそれぞれ動く。

## 4. クジラの出番係

### 自然に出てくるクジラ
- 次の出現までの間隔は30〜90分のランダム(平均約1時間)
- 出現時、次の割合で出方を選ぶ

| 出方 | 割合 | 目安 |
|---|---|---|
| 鳴き声だけ聞こえる | 25% | よくある |
| 潮吹きと背中 | 20% | よくある |
| 尾びれを上げて潜る | 15% | よくある |
| 親子で泳ぐ | 10% | ちょっとレア |
| 寝ているクジラ | 10% | ちょっとレア |
| 大ジャンプ | 20% | 約5時間に1回 |

- 直前と同じ出方は選ばない(選び直す)。このため実際の割合は表から少しずれるが許容する
- 間隔と割合は設定ファイルにまとめ、試作品を触りながら調整できるようにする

### 呼んだときのクジラ
- ボタンを押すと「呼んでいます…」と小さく表示する
- 10〜30秒後に近くへ来て、ザトウクジラの歌を歌い、最後に尾びれを見せて帰っていく
- 呼んだクジラがいる間は、呼ぶボタンを押せない
- 呼んだクジラがいる間は、自然出現のタイマーを止める。帰ったあとに再開する

### 共通ルール
- 鳴き声だけ以外の出方は、どのカメラ位置から見ても見える場所に出す
- おやすみモードでもクジラは出るが、音は鳴らさない
- 種類は基本ザトウクジラ。寝ている姿のみマッコウクジラ(縦に浮いて眠る姿)
- 開発用の隠しボタンで、各出方をすぐに出せるようにする

## 5. 音

### 波の音
- 途切れず、つなぎ目のわからないループで流す
- カメラ位置ごとに音を変える

| 位置 | 音 |
|---|---|
| 崖の上 | 遠くでうねる波 |
| 船の上 | 船体に当たるちゃぷちゃぷという水音 |
| 浜辺 | 波打ち際の寄せては返す音 |
| 水面すれすれ | 近くで揺れる水の音 |

- カメラ位置を変えたときは、数秒かけて音を入れ替える
- 素材は自由に使えるライセンスのものを探す(利用条件を記録する)

### クジラの声と水しぶき
- 鳴き声: NOAAのザトウクジラの歌(パブリックドメイン)。寝ているクジラ用にマッコウクジラの音も探す
- すべての音はフェードイン・フェードアウトで始まり、終わる
- **クジラの音は波の音より大きくならないよう上限をかける**。急な音量の跳ね上がりを防ぐ仕組み(リミッター)も通す
- 大ジャンプの水しぶきは、遠くでくぐもって聞こえる程度に抑える

### モードと音量
- おやすみモード: 波の音だけ。切り替え時、クジラの音は数秒かけて消える
- ふつうモード: 波の音にクジラの音が小さく混ざる。切り替え時、数秒かけて戻る
- 音量はスライダーで調整し、保存する

## 6. 見た目

### 海と空
- 既存のThree.jsの海(Water)と空(Sky)をベースにする
- 空は端末の時刻に合わせて朝・昼・夕方・夜と少しずつ変わる
- 夜は月明かりの海。画面全体を暗めにし、ナイトライトとして眩しすぎないようにする
- 夜でも月光の反射で、クジラの影や潮吹きがうっすら見えるようにする

### クジラの3Dモデル
| モデル | 用途 |
|---|---|
| ザトウクジラ(泳ぐ・潜る・ジャンプのアニメーション付き) | ほぼすべての出方 |
| 子クジラ | ザトウクジラのモデルを縮小して使う |
| マッコウクジラ | 寝ているクジラ |

- モデルはSketchfabなどからユーザーがダウンロードする
- ダウンロード時に、ストアで配布するアプリに使えるライセンスかを確認・記録する

### 演出
- 潮吹き: 霧状のしぶきが上がり、風に流れて消える
- 水しぶき: ジャンプや尾びれのときに飛び散る水
- 泡と波紋: クジラが浮上したあと、海面に白い泡と航跡がしばらく残る

### 軽さの工夫
- スマホでは自動で画質を下げ、なめらかさを優先する
- 画面が見えていないとき(タブ切り替え・画面オフなど)は描画を止める

## 7. 困ったときの動き

- クジラのモデルが読み込めない: 海と波の音はそのまま続ける。クジラの見た目が必要な出方は「鳴き声だけ」に置き換える
- 音のファイルが読み込めない: 画面は動かし続ける。波の音が読めない場合はメニューに小さく知らせる
- 保存した設定が読めない: 初期設定(ふつうモード・崖の上・中くらいの音量)で始める

## 8. 確かめ方

- **出番係の自動チェック**: 時間を早送りして何百回も出現させ、間隔(30〜90分)と各出方の割合がおおむね設計どおりか、同じ出方が連続しないかを確かめる
- **見た目の確認**: 隠しボタンで各出方を出し、4つのカメラ位置すべてから見えるか確認する
- **音の確認**: クジラの音が波の音を超えないこと、モード切り替えやカメラ切り替えで音が急に変わらないことを確認する

## 9. 完成の基準

1. タップすると波の音と海が始まり、ボタンのない海だけの画面になる
2. 4つのカメラ位置と、時刻による空の変化が動く
3. 6つの出方が、ほぼ設計どおりの頻度で自然に現れる
4. 呼ぶボタンで、クジラが来て歌って帰っていく
5. おやすみモードでクジラの音が消え、波の音だけになる
6. スマホのブラウザでもなめらかに動く
7. 実際に1時間ほど流して、音が途切れたり急に大きくなったりしない
